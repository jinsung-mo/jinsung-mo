# 모진성

Java와 Spring Boot를 주로 사용하는 신입 백엔드 개발자입니다.

사용자가 무엇을 하려는지 먼저 듣고, 기존 코드와 데이터가 어떻게 연결되는지 살펴봅니다. 오류가 나면 같은 상황을 만들어 원인을 찾고, 수정한 뒤에는 테스트로 다시 확인합니다. 웹 시스템을 만들고 안정적으로 운영하는 일을 하고 싶습니다.

[포트폴리오 보기](https://jinsung-mo.github.io/)

## 해결한 문제

- **요구사항이 달라졌을 때** — [CERTMAP](https://github.com/jinsung-mo/certmap)에서 취업 준비생 100명의 의견을 듣고, 자격증 추천보다 학습계획이 필요하다는 점을 확인했습니다. 서비스 방향을 바꾸면서 DB 구조와 API도 다시 설계했습니다.
- **같은 데이터가 여러 번 저장됐을 때** — [가볼래](https://github.com/jinsung-mo/gabolle-busan-travel)에서 동일한 생성 요청 8건이 동시에 들어오자 여행이 8개 만들어졌습니다. 요청 키를 먼저 확보하고 DB 고유 제약을 적용해 중복 저장을 막았습니다.
- **각 프로그램의 통신 규격이 달랐을 때** — [삐용](https://github.com/jinsung-mo/-BBIYONG-autonomous_driving_factory_patrol_robot)에서 로봇은 영상 헤더를 40바이트로 보냈지만 서버는 49바이트로 읽고 있었습니다. 실제 전송 데이터를 대조해 규격을 맞추고 연동 기준을 문서와 테스트 도구로 공유했습니다.
- **영상 분석 결과가 늦게 반영됐을 때** — [빈자리](https://github.com/jinsung-mo/Smart-Parking-Lot-Monitoring-Service_BINJAIR)에서 추론할 프레임을 줄이고 상태 전이 기준을 조정했습니다. 프로젝트 기록상 결과 반영 시간은 약 10초에서 3초 이내로 줄었습니다.

컴퓨터공학을 전공했고, SSAFY 15기 Java 과정에서 웹 개발을 공부했습니다. 정보처리기사 자격을 보유하고 있습니다.
